# مجلد النافذة الرئيسية (`ui/main_window`)

يحتوي هذا المجلد على مكونات النافذة الرئيسية (`MainWindow`) وإدارة المظهر والخلفيات والصفحات والصلاحيات في نظام GoldShop.

---

## فهرس الملفات ومسؤولياتها:

* `__init__.py`: تعريف `MainWindow` و`ToolsDialog` وتهيئة الواجهة الرئيسية ومسار `config.json`.
* `appearance.py`: إدارة التكبير/التصغير (`zoom_scale`)، وتطبيق السمات وملف الأنماط (`styles.qss`)، والقائمة الجانبية، وحفظ مستوى التكبير بأمان.
* `background.py`: تشغيل العمال الخلفيين (`AutoBackupWorker`، وتحديث `DuckDNS`، ومراقبة أوامر التشغيل) مع تحديث `config.json` ذرياً دون التأثير على باقي الإعدادات.
* `pages.py`: تحميل وإدارة الصفحات والتبويبات داخل `QStackedWidget`.
* `permissions.py`: اكتشاف وتطبيق صلاحيات العناصر والجداول تلقائياً حسب دور المستخدم.
