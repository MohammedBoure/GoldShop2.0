# مجلد إدارة الخزينة والصندوق (Coffre Magasin)

يحتوي هذا المجلد على واجهات إدارة الخزينة المركزية وخزنة المحل (`Coffre Magasin`) في نظام GoldShop، مع تصميم متناسق ومحدث يتماشى مع المظهر العام للنظام وواجهتي المبيعات واليومية (`Versement` و `Reports`).

---

## فهرس الملفات ومسؤولياتها:

### 1. `coffre_management_view.py`
* **الهدف:** واجهة الخزينة وإدارة الأصول النقدية، الدفع الإلكتروني، الديون، والمعادن الكسر (`CoffreMagasinView`).
* **الهيكل والتحسينات البصرية المطبقة:**
  * **شريط العنوان الموحد (Header Banner):** شريط علوي بارز بلون التيل القياسي للنظام (`#0f8f83`) مع خط عريض ونصوص واضحة متناسق مع واجهة الدفعات (`Versements`).
  * **شريط البطاقات الإحصائية (KPI Stat Cards):** بطاقات ملخصة علوية للأرصدة في الوقت الحقيقي تشمل:
    * إجمالي النقد (Espèces DA) بلون التيل الأساسي.
    * إجمالي الذهب الكسر (O.C Or g) بلون ذهبي دافئ.
    * إجمالي الفضة الكسر (O.C Argent g) بلون فضي أنيق.
    * إجمالي TPE & CCP (DA) للدفع الإلكتروني والبريدي.
    * إجمالي العملات الأجنبية (Devises € / $).
  * **شريط الفلترة والبحث السريع (Control Panel):**
    * فلترة ديناميكية حسب السنة والشهر.
    * حقل بحث متقدم (Debounced Search) بالبيان أو التاريخ أو المبلغ مع دعم فتح لوحة المفاتيح التفاعلية (`Touch`).
    * زر التحديث الفوري للأرصدة (`Actualiser`).
    * زر الإضافة الرئيسي (`+ Nouvelle Opération`).
  * **جدول تفصيلي احترافي بنمط إكسل (9 أعمدة):**
    * رأس جدول متناسق بلون التيل القياسي (`#0f8f83`).
    * خطوط شبكة ناعمة وتبادل ألوان الأسطر (`Alternating Row Colors`).
    * دعم النقر المزدوج على السطر لفتح نافذة التعديل المباشر.
    * قائمة كليك يمين عصرية (`Context Menu`) تحتوي على أيقونات واضحة لتعديل أو حذف العمليات.
    * سطر سفلي موحد للإجماليات (TOTAUX) مميز بلون التيل مع خطوط بيضاء عريضة ومطابقة لليومية (`excel_journal_view.py`).
  * **محدد الألوان البرمجي (`ColorOverrideDelegate`):**
    * ضمان عدم تجاوز ملف التنسيق العام (QSS) للألوان البرمجية المحددة للذهب، الفضة، الأرباح، والخسائر، وشريط الإجماليات.
  * **نافذة العمليات المحسنة (`OperationDialog`):**
    * واجهة متناسقة تدعم الشاشات التفاعلية بنقرة زر واحدة للوحة الأرقام الافتراضية وللمفاتيح.
    * أزرار تأكيد وإلغاء بألوان النظام المعتمدة.
