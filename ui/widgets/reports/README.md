# مجلد التقارير واليومية (Reports Widgets)

يحتوي هذا المجلد على واجهات التقارير واليومية المفصلة وجداول العمليات في نظام GoldShop.

---

## فهرس الملفات ومسؤولياتها:

### 1. `excel_journal_view.py`
* **الهدف:** واجهة يومية المبيعات بنمط إكسل (`ExcelJournalView`).
* **المحتوى:**
  * عرض ومتابعة المبيعات اليومية مع تفاصيل النقد (Recette)، الذهب الكسر (O.C)، الدفع الإلكتروني (TPE)، العملات الأجنبية (Euro, Dollar)، والملاحظات.
  * فلترة المبيعات بالسنة والشهر واليوم واسم الزبون والبائع.
  * إدخال وتعديل رأس مال البداية اليومي (Fond de Caisse - Fc).
  * تعديل وحذف المبيعات وحفظ الملاحظات وتغيير البائع.
  * عرض نافذة الأرباح التفصيلية والمحمية بكلمة مرور الإدارة (`SaleDetailsDialog`).
  * طباعة فواتير المبيعات بصيغة PDF وطباعتها حرارياً بأرقام فواتير نظيفة واحتساب التخفيضات بدقة.

### 2. `monthly_summary_view.py`
* **الهدف:** واجهة الحصيلة والملخص الشهري (`MonthlySummaryView`).
* **المحتوى:**
  * تجميع الإحصائيات الشهرية لحركة الصندوق والمبيعات والمدخولات والمصروفات.
  * عرض رسوم بيانية ومؤشرات الأداء المالي للمحل.
