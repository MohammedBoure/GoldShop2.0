# مجلد واجهات الموردين (Suppliers Widgets)

يحتوي هذا المجلد على واجهات ونوافذ إدارة الموردين، الحسابات الجارية، والعمليات المالية والمعدنية لنظام GoldShop.

---

## فهرس الملفات ومسؤولياتها:

* `__init__.py`: تهيئة حزمة واجهات الموردين وتصدير المكونات الرئيسية.
* `suppliers_view.py`: الواجهة الرئيسية الشاملة لإدارة الموردين واستعراض الحسابات والأرصدة والعمليات.
* `supplier_editor_dialog.py`: نافذة حوارية عائمة لإنشاء وتعديل بيانات المورد.
* `supplier_editor_form.py`: نموذج إدخال وتحرير بيانات المورد (الاسم، نوع المعدن، العيار الأساسي، الهاتف، العنوان، والبيانات الضريبية).
* `supplier_operation_dialog.py`: نافذة تسجيل عمليات التوريد والتسوية والمحاسبة بالوزن والقيمة النقدية للموردين.
