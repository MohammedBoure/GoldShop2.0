# قسم لوحة التحكم والإحصائيات (Dashboard Widgets)

يحتوي هذا المجلد على مكونات واجهة المستخدم المخصصة للوحة التحكم الرئيسية (Dashboard) في نظام GoldShop.

---

## فهرس الملفات ومسؤولياتها:

* `charts_section.py`: المخطط البياني المالي التفاعلي بنمط أعمدة البورصة (الداخل/المبيعات بالأخضر والخارج/المشتريات والمصاريف بالأحمر)، مزود بفلاتر تاريخية مخصصة للتحكم في التجميع الزمني (يومي، أسبوعي، شهري)، نطاقات زمنية مسبقة ومخصصة، وأنماط عرض متعددة مع بطاقات ملخص وشريط تحويم تفاعلي.
* `kpi_cards.py`: بطاقات مؤشرات الأداء الرئيسية (KPIs) لعرض إجمالي السيولة النقدية، ديون الزبائن، التزامات الموردين، وإجمالي أوزان الذهب والفضة.
* `alerts_section.py`: قسم التنبيهات الذكية الخاصة بنفاد المخزون، والقطع الراكدة التي لم تباع منذ فترات طويلة.
* `overview_tab.py`: التبويب الرئيسي الجامع لبطاقات المؤشرات، توزيع المخزون في الواجهة والخزنة، ومخطط التدفق المالي.
* `dashboard_view.py`: الحاوية العامة للوحة التحكم مع ميزات التجاوب للشاشات المختلفة والتحديث التلقائي لبيانات الإحصائيات.
