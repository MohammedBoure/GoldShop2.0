# Inventory UI Module (`ui/widgets/inventory`)

Ce module gère l'interface utilisateur pour la gestion des stocks, la saisie tactile des produits, les achats d'or cassé et les lots d'inventaire.

---

## Structure des fichiers :

* `achat_oc_view.py` : Vue et interface de gestion des achats d'or cassé (OC), calcul des poids, titres et règlements fournisseurs/clients.
* `touch_product_entry.py` : Interface de saisie rapide et tactile pour l'enregistrement des articles en inventaire.
* `inventory_list/` : Sous-module contenant les onglets de consultation, filtrage et formulaire détaillé de l'inventaire.
* `tabs_batches/` : Sous-module gérant les lots et regroupements d'articles de stock.
