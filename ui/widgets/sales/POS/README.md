# مجلد نقطة البيع (POS Widgets)

يحتوي هذا المجلد على مكونات وواجهات نقطة البيع السريعة والشاملة لنظام GoldShop.

---

## فهرس الملفات ومسؤولياتها:

* `pos_interface_widget.py`: واجهة نقطة البيع الرئيسية (`POSInterfaceWidget`) ونافذة الدفع المالي المتعدد (`POSCheckoutDialog`) التي تدعم الدفع نقداً (Cash)، البطاقة البنكية (TPE)، الذهب الكسر (Or Cassé)، الفضة الكسر (Argent Cassé)، العملات الأجنبية (Euro, Dollar)، وتحديد البائع والملاحظات.
* `pos_cart_manager.py`: إدارة سلة المشتريات، ضبط الكميات والأوزان، حساب الأسعار، وحفظ تصنيفات المعادن (ذهب / فضة) لكل صنف في السلة.
* `pos_ui_builder.py`: بناء الهيكل البصري والتخطيط العام لعناصر واجهة البيع.
* `pos_inventory_loader.py`: تحميل وعرض عناصر المخزون وفلترتها حسب الفئات والبحث السريع.
* `pos_client_manager.py`: إدارة اختيار وتعيين الزبائن وربطهم بعمليات البيع المباشرة أو المحجوزة.
* `pos_discount_manager.py`: إدارة التخفيضات والنسب الترويجية للبيع.
