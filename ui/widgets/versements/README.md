# مجلد واجهات العربون (Versements Widgets)

يحتوي هذا المجلد على جميع واجهات المستخدم (UI Dialogs & Widgets) الخاصة بإدارة ومتابعة ملفات العربون (Acomptes / Versements) وحجوزات القطع في نظام GoldShop.

---

## فهرس الملفات ومسؤولياتها:

### 1. `new_versement_dialog.py`
* **الهدف:** نافذة إنشاء ملف عربون جديد (`NewVersementDialog`).
* **المحتوى:**
  * البحث عن المنتجات وإضافتها للسلة بالباركود أو الاسم مع التوافق التام مع قارئ الباركود (AZERTY translation) وسلوك نقطة البيع (POS).
  * دعم الاستكمال التلقائي والبحث بالاسم مع نافذة اختيار للمطابقات المتعددة.
  * إمكانية تعديل ملاحظات/أوسمة كل قطعة (Observation / Notes) مباشرة عبر القائمة المنسدلة، الكتابة الحرة، أو زر لوحة المفاتيح الافتراضية ⌨️.
  * اختيار الزبون (Nominatif).
  * اختيار طريقة الدفع الأولى (دينار، أورو، دولار، ذهب مكسر، فضة مكسرة) عبر واجهة `QStackedWidget`.
  * حساب تلقائي لحظي وثنائي الاتجاه لطرق الدفع بالعملات الأجنبية والذهب/الفضة المكسرة (حساب الإجمالي تلقائياً من الوزن وسعر الغرام، أو حساب سعر الغرام/سعر الصرف تلقائياً من الإجمالي والوزن).
  * أدوات المساعدة في التخفيض (`Remise %`, `Prix Final`, `Prix/g Target`).
  * الحساب التلقائي اللحظي للوزن المقتنى (`Poids Déduit`) وعرض الأثر الفوري على الملف.

### 2. `add_payment_dialog.py`
* **الهدف:** نافذة إضافة دفعة مالية جديدة لملف مفتوح (`AddPaymentDialog`).
* **المحتوى:**
  * عرض منقسم (Split View) يعرض تفاصيل الملف والقطع والملاحظات وسجل الدفعات في الجانب الأيسر.
  * جدول القطع المكون من 7 أعمدة منظمة بدقة (`Statut`, `Désignation`, `Poids Initial`, `Prix Estimé`, `Déduit`, `Reste`, `Note / Obs`).
  * إمكانية تعديل ملاحظات وأوسمة القطع مباشرة بالنقر المزدوج (Double-Click) أو عبر القائمة المنبثقة بالزر الأيمن للفأرة (Context Menu).
  * اختيار وجهة الدفعة (الملف ككل أو قطعة محددة).
  * توحيد طرق الدفع بالتبويب الأنيق (`QStackedWidget`) تشمل الدينار، الأورو، الذهب المكسر، الدولار، والفضة المكسرة مع الحساب التلقائي اللحظي وثنائي الاتجاه لمعادلات الصرف وسعر الغرام/الإجمالي.
  * أدوات التخفيض والحساب التلقائي للوزن المقتنى المتطابقة 100% مع واجهة الإنشاء.
  * دعم تسجيل مبالغ نقدية سالبة مباشرة وسلسة عند إرجاع الأموال أو رد الفائض دون واجهات مساعدة معقدة.

### 3. `edit_payment_dialog.py`
* **الهدف:** نافذة تعديل وتصحيح دفعة سابقة (`EditPaymentDialog`).
* **المحتوى:**
  * ملء بيانات الدفعة السابقة تلقائياً وتحديد طريقة الدفع (دينار، أورو، ذهب كسر، دولار، فضة كسر) والمبالغ والعملات.
  * جدول القطع المكون من 7 أعمدة متطابق في التوزيع والمحاذاة مع نافذة الإضافة.
  * إمكانية تعديل ملاحظات القطع مباشرة بالنقر المزدوج أو القائمة المنبثقة وحفظ التحديثات لحظياً.
  * دعم كامل للحساب التلقائي اللحظي وثنائي الاتجاه لمعادلات الصرف للعملات الأجنبية والذهب/الفضة الكسر (الوزن وسعر الغرام يعطي الإجمالي، أو الإجمالي والوزن يعطي سعر الغرام).
  * إعادة حساب الأساس المالي للرصيد المتاح وتحديث الوزن المقتنى فورياً وبنفس المنطق الحسابي الموحد.
  * دعم تعديل وتصحيح عمليات رد الفائض والمبالغ السالبة بأمان ومرونة تامة.

### 4. `versements_view.py`
* **الهدف:** الشاشة الرئيسية لمتابعة وإدارة ملفات العربون (`VersementsView`).
* **المحتوى:**
  * جدول عرض ملفات العربون مع القطع والدفعات والتفاصيل المالية وتمييز دفعات الذهب والفضة الكسر.
  * فصل واضح بين وسم/ملاحظة الفاتورة (`custom_note` / `Facture`) والملاحظة الداخلية الخاصة بالمتجر (`observation` / `Obs`).
  * أزرار العمليات الواضحة في الشريط العلوي والقوائم المنبثقة (تعديل الملاحظات، إضافة دفعة، تعديل دفعة، إلغاء، استلام، تسليم مع فاتورة، طباعة وصولات PDF والحرارية).
  * خيار الطباعة المخصصة مع الملاحظات (`open_print_notes_dialog`) عبر زر الشريط العلوي ("Imprimer avec Note") والقائمة المنبثقة ("Imprimer avec Note / Options...") ونافذة التفاصيل الشاملة، مع دعم التمرير التلقائي للبيانات المخصصة إلى محركات PDF والطباعة الحرارية.
  * إمكانية عرض وتعديل الملاحظات بنقرة واحدة أو بالنقر المزدوج (Double-Click) على أسطر القطع أو من نافذة التفاصيل الشاملة وحفظها مباشرة في قاعدة البيانات.
  * التصفية حسب الحالة (En Cours, Clôturé, Annulé, Tous) والبحث والترقيم (Pagination).

### 5. `invoice_note_selector.py`
* **الهدف:** مكوّن مساعد لإدارة وتحديد وسوم وملاحظات القطع ونافذة خيارات الطباعة المخصصة مع الملاحظات لكافة عمليات الدفع والقطع.
* **المحتوى:**
  * أدوات إدارة وسوم وملاحظات القطع (`create_invoice_note_combo`, `normalize_custom_note`, `selected_custom_note`).
  * نافذة خيارات الطباعة والملاحظات المخصصة المحدثة بتبويبات عصرية (`VersementPrintNoteDialog`):
    * **تبويب ملاحظات عمليات الدفع (💵 Notes des Paiements):**
      * جدول مخصص لكل عملية وسطر دفع يعرض تاريخ العملية ونوعها ومبلغها.
      * مربع اختيار مستقل (`Afficher ?`) لكل سطر دفع لتحديد إظهار أو إخفاء الملاحظة بدقة على الوصل.
      * حقل نصي تفاعلي وقابل للتعديل لكل سطر دفع لتعديل نص الملاحظة بحرية قبل الطباعة مع التفعيل التلقائي لمربع الاختيار بمجرد الكتابة.
      * أزرار التحديد والإلغاء السريع لجميع سطور الدفع بنقرة واحدة (`Tout afficher` / `Tout masquer`).
      * خيار اختياري لحفظ تعديلات ملاحظات أسطر الدفع في قاعدة البيانات (`Versement_Payments.notes`).
    * **تبويب الملاحظة العامة للوصل (📝 Note Générale du Bon):**
      * تفعيل/إلغاء إظهار ملاحظة عامة على وصل العربون مع نماذج سريعة جاهزة والكتابة الحرة وزر لوحة المفاتيح الافتراضية.
    * **تبويب ملاحظات القطع المحجوزة (📦 Notes des Articles):**
      * جدول تفاعلي بالقطع المحجوزة للتحكم في ظهور ملاحظات كل قطعة وتعديلها وخيار الحفظ في قاعدة البيانات.
    * **دعم شاشات اللمس ونقاط البيع (Touch POS & Virtual Keyboard):**
      * توفير زر لوحة مفاتيح افتراضية (`Clavier Tactile`) في الشريط السفلي للنافذة، وشريط الإجراءات السريعة لكل تبويب، وبجانب كل حقل ملاحظة داخل الجداول لسهولة الكتابة المباشرة باللمس.
      * إغلاق سلس وتلقائي للوحة المفاتيح الافتراضية عند قبول أو إلغاء النافذة.
    * **التكيف مع مختلف أبعاد ودقات الشاشات (Responsive Scaling):**
      * أبعاد ديناميكية متجاوبة تتكيف تلقائياً مع الشاشات الصغيرة (1024x768 / 1280x800) وشاشات Full HD وتحديد موقع ملائم يتيح مساحة ظهور مريحة للوحة المفاتيح السفلية.
    * **شريط الإجراءات والطباعة المتناسق مع ثيم النظام:**
      * معاينة PDF، طباعة PDF مباشرة، وطباعة التذكرة الحرارية، وزر لوحة المفاتيح الافتراضية، وزر الإلغاء.
      * تصميم متناسق ومطابق لثيم البرنامج الأساسي (Teal/Gold `#0f8f83`, Dark Slate `#2c3e50`, Slate `#334155`, Light Gray `#f8fafc`) في واجهة المستخدم، وفي وصولات PDF والتذاكر الحرارية.
