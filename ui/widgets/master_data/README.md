# مجلد تبويبات البيانات المرجعية (Master Data Widgets)

يحتوي هذا المجلد على تبويبات واجهة المستخدم لإدارة البيانات المرجعية والأساسية لنظام GoldShop.

---

## فهرس الملفات ومسؤولياتها:

* `suppliers_tab.py`: واجهة إدارة قائمة الموردين، نوع المعدن المعتمد (ذهب / فضة)، العيار الاساسي (750 / 925)، ومعلومات الاتصال والعنوان مع دعم شاشات اللمس والبحث السريع.
* `clients_tab.py`: واجهة إدارة سجل الزبائن ومعلومات الاتصال والملاحظات.
* `categories_tab.py`: إدارة تصنيفات المنتجات والقطع.
* `product_names_tab.py`: إدارة التسميات والأسماء القياسية للمنتجات.
* `metals_tab.py`: إدارة أنواع المعادن والأصناف والعيارات ونسب النقاوة.
* `locations_tab.py`: إدارة مواقع وأماكن التخزين الفيزيائية للمنتجات.
* `treasury_locations_tab.py`: إدارة مواقع الخزائن وصناديق الكاش (Caisse / Coffre).
* `expense_categories_tab.py`: إدارة بنود وتصنيفات المصاريف التشغيلية.
* `invoice_notes_tab.py`: إدارة الملاحظات المسبقة للفواتير والوصولات.
