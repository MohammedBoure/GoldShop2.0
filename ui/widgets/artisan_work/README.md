# مجلد واجهة الورشة وتصليحات الحرفيين (Artisan Work Widgets)

يحتوي هذا المجلد على الواجهات والنوافذ الحوارية الخاصة بإدارة ومتابعة طلبات التصليح، الصيانة، والتحويل مع الحرفيين وأصحاب الورشات الخارجية ومحاسبة الزبائن.

---

## فهرس الملفات ومسؤولياتها:

* `__init__.py`: تهيئة حزمة واجهات الورشة والتصليحات.
* `artisan_work_view.py`:
  * **الواجهة الرئيسية (`ArtisanWorkView`):**
    * عرض ومتابعة جدول أوامر الإنتاج والتصليح (Tableau de Production) مع الفلترة حسب الحرفي، حالة الطلب (لدى المستقبل، عند الصانع، عاد للمستقبل، تم تسليمه للزبون)، والبحث.
    * إدارة الحرفيين (إضافة حرفي، تعديل، حذف، وسجل الحركات).
    * إتاحة النقر المزدوج والقوائم السياقية لتعديل الفيشات وتغيير الحالات بسرعة.
  * **نافذة الفيشة والأمر الحوارية (`OrderDialog`):**
    * تسجيل وتعديل تفاصيل طلب الورشة (الزبون والمالك، رقم الفيشة، الحرفي المعين، تاريخ التسليم والاستلام والخروج، الوزن قبل وبعد، سعر التكلفة وسعر البيع وحساب الفارق/الأرباح تلقائياً).
    * **تجربة المستخدم اللمسية والمنطقة الآمنة للوحة المفاتيح (Keyboard Safe Zone & Touch Ergonomics):**
      * شريط علوي ثابت (Sticky Header Actions) لأزرار الحفظ ("Enregistrer l'Opération") والإلغاء ("Annuler") لضمان عدم حجبها أو تغطيتها نهائياً عند ظهور لوحة المفاتيح الافتراضية أو لوحة الأرقام.
      * وضع النموذج كاملاً داخل منطقة تمرير لمسي ديناميكية (`QScrollArea` + `QScroller`) تدعم السحب والتمرير السلس.
      * التمرير التلقائي الفوري (`_auto_scroll_to`) عند التركيز على أي حقل نصي ليكون في الثلث العلوي من الشاشة فوق لوحة المفاتيح.
      * ملاءمة المقاييس اللمسية (Touch Targets $\ge 44\text{px}-48\text{px}$) لكافة الحقول والأزرار المساعدة (الكيبورد، الأرقام، التاريخ، والتقويم) لتفادي الضغطات الخاطئة.
    * **تسديد ودفعات الزبون (Règlement & Paiement Client):**
      * إمكانية الدفع نقداً بالدنانير (Espèces DA) مع إتاحة إدخال قيم سالبة عبر لوحة أرقام لمسية تدعم الزر `+/-` في حال إرجاع أو رد مبالغ للزبون.
      * إمكانية الدفع عبر جهاز الدفع الإلكتروني (TPE DA).
      * إمكانية الدفع بالذهب الكسر (Or Cassé OC) بالجرامات.
      * إمكانية الدفع بالفضة الكسر (Argent Cassé OC) بالجرامات.
      * ربط الدفعات تلقائياً برقم الجلسة اليومية (`journee_id`) لتظهر وتُقيد في تقرير اليومية وسجل المبيعات.
