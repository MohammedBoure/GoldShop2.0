# مجلد إعدادات النظام وتخصيص الطابعات (`ui/widgets/settings`)

يحتوي هذا المجلد على وحدات واجهة إعدادات البرنامج وضبط الطابعات وقواعد البيانات وإدارة المستخدمين والوصول عبر الويب لنظام GoldShop 2.0.

---

## فهرس الملفات ومسؤولياتها:

* `settings_tab.py`: تبويبة الإعدادات الرئيسية (`SettingsTab`)، تجمع الإعدادات العامة (اسم المتجر، العملة، الحفظ التلقائي)، إعدادات العرض والتكبير، الطابعة الحرارية، طابعة الباركود والملصقات، إعدادات تصدير PDF، وإعدادات الاتصال بقاعدة البيانات.
* `thermal_printer_tab.py`: إعدادات الطابعة الحرارية الخاصة بإيصالات وفواتير الزبائن (`ThermalPrinterTab`)، تشمل اختيار المنفذ واسم الطابعة وتنسيق الأسطر والقص التلقائي.
* `label_printer_tab.py`: إعدادات طابعة ملصقات الباركود للقطع الذهبية والمجوهرات (`LabelPrinterSettingsTab`)، تشمل أبعاد الملصق ومواقع العناصر والخطوط.
* `pdf_printer_tab.py`: إعدادات طباعة وتوليد مستندات وفواتير PDF (`PdfPrinterTab`)، تشمل الهوامش والترويسة وحجم الصفحة.
* `users_view.py`: واجهة إدارة المستخدمين والصلاحيات (`UsersView`)، تشمل إضافة وتعديل المستخدمين وتعيين الأدوار وكلمات المرور.
* `web_access_settings.py`: واجهة إعدادات أمان وحماية الوصول عن بعد عبر متصفح الويب والهاتف المحمول (`WebAccessSettingsWidget`).
