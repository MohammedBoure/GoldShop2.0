# مجلد قوالب الويب (HTML Templates)

يحتوي هذا المجلد على قوالب Jinja2 الخاصة بواجهة الويب والهاتف المحمول لنظام GoldShop 2.0، والمصممة بنمط الإضاءة النهاري (ERP Clair Light Mode) ومطابقة لترتيب الأزرار وعناصر التحكم في واجهات برنامج سطح المكتب.

---

## فهرس الملفات ومسؤولياتها:

* `base.html`: القالب الهيكلي الأساسي بنمط ERP Clair، يشمل الشريط العلوي باللون الأخضر المميز (`#0f8f83`)، أزرار اللغة والتحديث والقفل الأمني، وشريط التنقل السفلي الثابت (Bottom Navigation Bar) للتنقل السريع بين الأقسام الخمسة.
* `index.html`: شاشة لوحة التحكم الرئيسية المضيئة، تعرض بطاقة تسعيرة الذهب المرجعي الحية وبطاقات الانتقال السريع للأقسام الخمسة.
* `journal.html`: شاشة اليومية بنمط إكسل المطابقة طبق الأصل لـ `excel_journal_view.py`:
  - السطر الأول: قوائم اختيار السنة والشهر واليوم، وزر `Afficher le Journal` (أخضر تيل)، وزر `Fc (Caisse)` (برتقالي)، وزر `+ Nouvelle Vente` (أخضر).
  - السطر الثاني: حقل البحث عن الزبون أو التعيين، وقائمة اختيار البائع.
  - جدول إكسل بالأعمدة التسعة: Désignation, P.S, Recette, O.C, TPE, Euro, Dollar, Vendeur, Observation، مع سطر رأس اليومية وسطر الإجماليات الشامل.
* `monthly_summary.html`: شاشة الحصيلة والملخص الشهري المطابقة لـ `monthly_summary_view.py`:
  - شريط التحكم العلوي: اختيار السنة والشهر، وزر `Afficher le Tableau` (أخضر تيل)، وشارة `Session Admin active`.
  - لافتة العنوان العريضة `RÉSUMÉ MENSUEL DES RECETTES`.
  - جدول إكسل الشامل بالأعمدة الـ 12 مع مؤشرات الأرباح الصافية (الفائدة) لكل يوم وسطر الإجمالي العام.
* `versements.html`: شاشة العربون وحجوزات الزبائن المطابقة لـ `versements_view.py`:
  - شريط البحث وحالة الملف، وزر `+ Nouveau Versement` الأخضر.
  - شريط الإجراءات: `Détails Articles`، `Bon (PDF)`، `Paiement Global`، و `Clôturer`.
  - جدول الحسابات بالأعمدة التسعة مع تمييز الأوزان المحجوزة والمقتناة والدفعات.
* `artisan_work.html`: شاشة الورشة والتصليحات والحرفيين المطابقة لـ `artisan_work_view.py`:
  - علامتا التبويب `Réparations (Production Excel)` و `Artisans & Soldes`.
  - فلاتر البحث والمدة الزمنية والحالات، وزر `Nouveau Dépôt Atelier`.
  - جدول أوامر الإنتاج الكامل بالأعمدة الـ 14 مع حساب أجور الصياغة وفوارق الأرباح.
* `suppliers.html`: شاشة دفتر الموردين المطابقة لـ `suppliers_view.py`:
  - الشريط العلوي: قائمة منسدلة بجميع الموردين الـ 37 مع زر التحديث.
  - بطاقة الرأس البارزة: اسم المورد، وشارتي `Poids Net: X.XX g` و `Solde: X DA`.
  - شريط الإجراءات: `Nouvelle Opération`، `Modifier`، `Supprimer`، و `Changer Couleur`.
  - جدول دفتر الأستاذ الفرنسي بالأعمدة الخمسة (Date, Poids, Afaçon, Montant, Obs/Libellé) مع تمييز الألوان وسطر الإجماليات.
