# مجلد قوالب الويب (HTML Templates)

يحتوي هذا المجلد على قوالب Jinja2 الخاصة بواجهة الويب والهاتف المحمول لنظام GoldShop 2.0، والمصممة لتوفير تجربة استخدام سريعة ومتجاوبة مع الهواتف الذكية (Mobile-First).

---

## فهرس الملفات ومسؤولياتها:

* `base.html`: القالب الهيكلي الأساسي، يشمل وسوم الموبايل (Viewport وSafe Area)، الشريط العلوي مع زر تبديل اللغة وتحديث البيانات، شريط التنقل السفلي الثابت (Bottom Navigation Bar) للتنقل السريع بين الأقسام الخمسة، ونافذة المصادقة الأمنية المنبثقة.
* `index.html`: شاشة لوحة التحكم الرئيسية للهاتف، تعرض بطاقة تسعيرة الذهب المباشرة، وبطاقات الوصول السريع للأقسام الخمسة.
* `journal.html`: شاشة اليومية بنمط إكسل المطابقة لـ `excel_journal_view.py`، تعرض بطاقات مؤشرات الأداء الثمانية (Fc، Recette، P_S Or/Argent، O.C Or/Argent، TPE، Devises)، وتدعم التبديل بين بطاقات الهاتف وجدول إكسل القابل للتمرير الأفقي.
* `monthly_summary.html`: شاشة الحصيلة والملخص الشهري المطابقة لـ `monthly_summary_view.py`، تعرض بطاقات الإيرادات والأرباح الصافية (الفائدة) لكل يوم مع سطر الإجماليات الشامل.
* `versements.html`: شاشة العربون وحجوزات الزبائن المطابقة لـ `versements_view.py`، تعرض الملفات الجارية والمكتملة، وتفاصيل القطع المحجوزة والأوزان المقتناة والمتبقية، وتدعم الاتصال الهاتفي المباشر بالزبون.
* `artisan_work.html`: شاشة الورشة والتصليحات والحرفيين المطابقة لـ `artisan_work_view.py`، تتيح التبديل بين جدول أوامر الإنتاج بنموذج إكسل الكامل وكشف حسابات وأرصدة الذهب الخالص للحرفيين.
* `suppliers.html`: شاشة دليل الموردين ودفتر الأستاذ المطابقة لـ `suppliers_view.py`، تعرض بطاقات الموردين وأرصدتهم، وتفتح جدول دفتر إكسل الفرنسي بأعمدته الخمسة (Date, Poids, Afaçon, Montant, Obs/Libellé).
