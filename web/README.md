# مجلد طبقة الويب وواجهة التطبيقات البرمجية (Web Layer & API)

يحتوي هذا المجلد على مكونات خادم الويب المدمج (Flask) ونقاط الاتصال البرمجية (REST APIs) لنظام GoldShop 2.0، والمخصصة حصراً للقراءة والاستعلام (Strictly Read-Only) لتوفير البيانات للمتابعة عن بعد، وعرض التقارير، واستعراض شاشات اليومية والحصيلة والعربون والورشة والموردين بأمان تام، مع حظر ومنع كافة عمليات التعديل أو الكتابة على البيانات نهائياً.

---

## فهرس الملفات ومسؤولياتها:

* `__init__.py`: تهيئة حزمة الويب وتصدير الأدوات المساعدة.
* `security.py`: إدارة الأمان وحماية الويب، تشمل التحقق من كلمة مرور الويب المشفرة (`X-GoldShop-Password`)، منع الهجمات المتكررة وتحديد معدل الطلبات (Rate Limiting)، وتسجيل المحاولات الفاشلة.
* `routes/`: مجلد مسارات وخدمات الويب المقسمة معمارياً لدعم كافة واجهات النظام وخدمة صفحات واجهة الهاتف.
* `templates/`: مجلد قوالب Jinja2 لواجهة الهاتف المحمول ولوحة التحكم وشاشات اليومية، الحصيلة الشهرية، العربون، الورشة، والموردين.
* `static/`: مجلد الأصول الثابتة ويشمل ملف التنسيق المتجاوب `css/mobile.css` ووحدات جافاسكريبت التفاعلية `js/`.
