# مجلد طبقة الويب وواجهة التطبيقات البرمجية (Web Layer & API)

يحتوي هذا المجلد على مكونات خادم الويب المدمج (Flask) ونقاط الاتصال البرمجية (REST APIs) لنظام GoldShop 2.0، والمخصصة لتوفير البيانات للمتابعة عن بعد، وعرض التقارير، والدمج مع واجهات البرنامج المختلفة.

---

## فهرس الملفات ومسؤولياتها:

* `__init__.py`: تهيئة حزمة الويب وتصدير الأدوات المساعدة.
* `security.py`: إدارة الأمان وحماية الويب، تشمل التحقق من كلمة مرور الويب المشفرة (`X-GoldShop-Password`)، منع الهجمات المتكررة وتحديد معدل الطلبات (Rate Limiting)، وتسجيل المحاولات الفاشلة.
* `routes/`: مجلد مسارات وخدمات الويب المقسمة معمارياً لدعم كافة واجهات النظام.
