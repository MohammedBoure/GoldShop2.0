# مجلد ملفات جافاسكريبت (JavaScript Client)

يحتوي هذا المجلد على وحدات التحكم البرمجية من جانب العميل (Client-side JavaScript) لتشغيل واجهة الويب التفاعلية والمتجاوبة مع الهواتف المحمولة لنظام GoldShop 2.0.

---

## فهرس الملفات ومسؤولياتها:

* `app.js`: وحدة التحكم الأساسية للنظام، تدير المصادقة الأمنية (`X-GoldShop-Password` وكعكات الجلسة `cookies`)، ومعالجة أخطاء الشبكة، ودوال التنسيق المالي (الدينار الجزائري DA) وتنسيق أوزان الذهب والفضة (غرام g)، والتنبيهات المنبثقة (Toasts)، وتبديل اللغات.
* `journal.js`: وحدة إدارة شاشة اليومية بنمط إكسل، تجلب وتصفي الجلسات النقدية والمبيعات حسب التاريخ والبائع، وتدعم التبديل بين العرض البطاقي للهاتف (Mobile Cards) والجدول الموسع المطابق لـ `excel_journal_view.py`.
* `monthly.js`: وحدة إدارة شاشة الحصيلة الشهرية، تتولى اختيار الشهر والسنة وعرض مؤشرات الأداء وحساب الأرباح الصافية (الفائدة) لكل يوم وشريط الإجماليات الشامل المطابق لـ `monthly_summary_view.py`.
* `versements.js`: وحدة إدارة ملفات وحجوزات العربون، تدعم البحث الفوري والفلترة بالحالة، وعرض تفاصيل القطع والأوزان المقتناة والمتبقية، وتواريخ الدفعات، والاتصال الهاتفي بالزبون بنقرة واحدة وفق `versements_view.py`.
* `artisan.js`: وحدة إدارة الورشة والتصليحات، تتيح التبديل بين جدول أوامر الإنتاج بنموذج إكسل الكامل، واستعراض أرصدة الحرفيين (ذهب خالص 24K وأجور الصياغة DA) مع كشف الحسابات المطابق لـ `artisan_work_view.py`.
* `suppliers.js`: وحدة إدارة دفتر الموردين، تعرض بطاقات الموردين مع الأرصدة الحالية (Poids Net و Solde DA)، وتفتح جدول دفتر الأستاذ بنمط إكسل الفرنسي بأعمدته الخمسة وتمييز التنبيهات والألوان وفق `suppliers_view.py`.
