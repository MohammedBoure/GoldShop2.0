# مجلد الأصول الثابتة للويب (Web Static Assets)

يحتوي هذا المجلد على الأصول الثابتة لواجهات الويب والهاتف المحمول لنظام GoldShop 2.0.

---

## فهرس المجلدات ومسؤولياتها:

* `css/`: ملفات التنسيق والأنماط، ويشمل `mobile.css` المخصص لواجهة الهاتف المحمول مع دعم اللمس، والمناطق الآمنة للشاشة، والاتجاهين العربي والفرنسي.
* `js/`: ملفات البرمجة التفاعلية من جانب العميل، وتشمل وحدة التحكم الأساسية `app.js` ووحدات العرض التفصيلية لكل من اليومية، والحصيلة الشهرية، والعربون، والورشة، والموردين.
