# مجلد ملفات التنسيق والأنماط (CSS)

يحتوي هذا المجلد على ملفات التنسيق والتصميم لواجهة الهاتف والويب المتجاوبة لنظام GoldShop 2.0.

---

## فهرس الملفات ومسؤولياتها:

* `mobile.css`: ملف التنسيق الأساسي المخصص لواجهات الهاتف المحمول، يتميز بتصميم داكن فاخر بلمسات ذهبية عصرية، ويدعم الشاشات اللمسية، ومناطق الأمان للهواتف الحديثة (Safe Area Insets)، والاتجاهين العربي (RTL) والفرنسي (LTR)، والشبكات المتجاوبة لبطاقات المؤشرات (KPIs) وجداول البيانات.
