# مجلد مسارات وخدمات الويب (Web Routes)

يحتوي هذا المجلد على وحدات تسجيل وتوجيه طلبات الويب وREST API لنظام GoldShop 2.0، والمصممة لتطابق تماماً بنية البيانات المعروضة في واجهات سطح المكتب الرئيسية.

---

## فهرس الملفات ومسؤولياتها:

* `__init__.py`: نقطة تصدير دوال تسجيل المسارات لكافة الوحدات الفرعية.
* `core.py`: مسارات النظام الأساسية وتشمل فحص الاتصال وقاعدة البيانات (`/api/v1/health`)، التحقق من صلاحية الجلسة وكلمة المرور (`/api/v1/auth/check`)، فهرس ودليل نقاط الاتصال البرمجية (`/api/v1`)، لوحة المؤشرات العامة (`/api/v1/dashboard`)، وتحديث سعر الذهب وإعادة تسعير المخزون (`/api/v1/market-price/gold`).
* `reports.py`: مسارات التقارير المطابقة لواجهات اليومية والحصيلة الشهرية:
  * **اليومية بنمط إكسل (`/api/v1/reports/journal`):** مطابقة لواجهة `excel_journal_view.py`، تجلب الجلسات والمبيعات والدفعات وأعمال الورشة مجمعة مع فصل دقيق لأوزان الذهب والفضة، النقد، الذهب والفضة الكسر، الدفع الإلكتروني والعملات الصعبة، ورأس مال البداية (Fc)، وقائمة البائعين (`/api/v1/reports/journal/sellers`).
  * **الحصيلة الشهرية (`/api/v1/reports/monthly-summary`):** مطابقة لواجهة `monthly_summary_view.py`، تجمع الإيرادات اليومية وحركة الصندوق والأرباح الصافية (الفائدة / Bénéfice) لكل يوم من أيام الشهر مع سطر الإجماليات الشامل.
* `versements.py`: مسارات ملفات وحجوزات العربون (`/api/v1/versements`):
  * مطابقة لواجهة `versements_view.py`، توفر عرضاً هرمياً للملفات مع القطع المحجوزة، حساب الأوزان المقتناة والمتبقية لكل قطعة بدقة، الفصل بين وسم الفاتورة والملاحظة الداخلية الخاصة بالمتجر، سجل الدفعات، بطاقات الملخص، والإحصائيات العامة (`/api/v1/versements/stats`).
* `artisan_work.py`: مسارات الورشة وتصليحات الحرفيين (`/api/v1/artisan-work`):
  * مطابقة لواجهة `artisan_work_view.py`، تشمل جدول أوامر الإنتاج والتصليح (`/api/v1/artisan-work/orders`) بنموذج إكسل الكامل (numero, Nom, Tel, date remis, Obj, Poid, Date Reçue, Date Sortie, Prix Façon, Prix Client, Diff, Statut, Artisan)، ودليل الحرفيين وأرصدة الذهب وأجور الصياغة وكشوف الحسابات (`/api/v1/artisan-work/artisans`).
* `suppliers.py`: مسارات دفتر الموردين والحسابات الجارية (`/api/v1/suppliers`):
  * مطابقة لواجهة `suppliers_view.py`، تشمل دليل الموردين مع بطاقة الأرصدة اللحظية (Poids Net و Solde DA)، والجدول التفصيلي لدفتر الموردين بنمط إكسل الفرنسي (`/api/v1/suppliers/<id>/ledger`) بأعمدته الخمسة (Date, Poids, Afaçon, Montant, Obs/Libellé) مع تمييز القيم الموجبة والسالبة وألوان التسوية.
* `operations.py`: مسارات العمليات التشغيلية وتشمل استعراض المبيعات وتفاصيلها (`/api/v1/sales`)، المخزون والبحث بالباركود (`/api/v1/inventory`)، الزبائن والأرصدة (`/api/v1/clients`)، الخزينة المركزية (`/api/v1/coffre`)، مواقع الصناديق (`/api/v1/treasury`)، المصاريف (`/api/v1/expenses`)، البيانات المرجعية (`/api/v1/references`)، ومحرك البحث الشامل (`/api/v1/search`).
* `partners.py`: وحدة توافقية سابقة توجه طلبات الشركاء والموردين إلى `suppliers.py`.
