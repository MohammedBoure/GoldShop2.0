# مجلد الخدمات الخلفية (Services)

يحتوي هذا المجلد على الخدمات التشغيلية والمراقبة المستقلة عن واجهة المستخدم.

---

## فهرس الملفات ومسؤولياتها:

* `__init__.py`: تهيئة حزمة الخدمات.
* `duckdns.py`: تحديث سجل DuckDNS التلقائي مع إعادة المحاولة عند الأعطال المؤقتة.
* `runtime_control.py`: إدارة أوامر التحكم في التشغيل وتسجيل الخروج الإجباري عبر الأجهزة.
* `web_server.py`: إدارة وإشراف خادم الويب المدمج (`WebServerManager`) لضمان استمرارية عمل خدمة الويب وإعادة تشغيلها تلقائياً طوال فترة تشغيل التطبيق.
