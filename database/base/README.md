# مجلد البنية الأساسية لقاعدة البيانات (Database Base)

يحتوي هذا المجلد على وحدات الاتصال الأساسية وإنشاء جداول قاعدة البيانات وترحيل المخططات والنسخ الاحتياطي والاستعادة.

---

## فهرس الملفات ومسؤولياتها:

* `__init__.py`: تهيئة الحزمة وتصدير فئة `Database` المركزية والثوابت المساعدة.
* `config.py`: مسارات التشغيل الخارجية (`get_external_path`) وترتيب استيراد الجداول ومُشفّر JSON المخصص.
* `connection.py`: إدارة مجمع الاتصال (`MySQLConnectionPool`) ومحرك `SQLAlchemy` مع إدارة المعاملات (`get_db_connection`) والتحقق من إنشاء قاعدة البيانات.
* `database.py`: الفئة المركزية `Database` (Singleton متزامن الخيوط) التي تجمع وحدات الاتصال والمخطط والنسخ الاحتياطي والأرشيف.
* `tables.py`: تعريف مخططات وجداول النظام الأساسية وترقيات الحقول التلقائية (Migrations).
* `views_indexes.py`: تعريف العروض (Views) والفهارس (Indexes) في قاعدة البيانات.
* `schema_initializer.py`: تهيئة المخطط والتحقق من بصمة الجداول عند بدء التشغيل.
* `backup_manager.py`: النسخ الاحتياطي والاستعادة الذرية (CSV وExcel) داخل معاملات قابلة للتراجع (`rollback`)، التحقق الصارم من أسماء الجداول والأعمدة، حماية فك الضغط من Zip Slip، وإلزام `pyzipper` عند تفعيل التشفير.
* `archive_view_manager.py`: إدارة وضع عرض الأرشيف للقراءة فقط من ملفات ZIP مع التحقق من سلامة الجداول والأعمدة والملفات.
