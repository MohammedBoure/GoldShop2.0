# سكربتات التشخيص اليدوية (Diagnostics)

يحتوي هذا المجلد على سكربتات التحقق والتشخيص اليدوية التي تتصل مباشرة بقاعدة البيانات المحلية، وقد تم عزلها عن `tests/` حتى لا تُنفَّذ أثناء تشغيل الاختبارات الآلية.

---

## فهرس الملفات:

* `test_annule.py`: عرض عناصر العربون الملغاة (`ANNULE`) من قاعدة البيانات.
* `test_duplicates.py`: فحص تكرار حجوزات المخزون النشطة (`EN_COURS`) في `Versement_Items`.
* `test_failures.py`: فحص إمكانية استعادة آخر 50 عنصر عربون ملغى.
* `test_flow.py`: تجربة يدوية لإنشاء عربون وإلغائه واستعادته ثم حذفه.
* `test_items.py`: عرض سجل `Versement_Items` لمادة محددة بالمخزون.
* `test_restore.py`: فحص استعادة آخر عنصر عربون ملغى.
* `test_restore_2.py`: فحص استعادة عنصر ملغى غير محجوز حالياً.
* `test_v2.py`: استعلام سريع لحالة عربون محدد.
* `test_zero_weight.py`: عدّ المواد ذات الوزن الصفري أو غير المحدد في المخزون.
