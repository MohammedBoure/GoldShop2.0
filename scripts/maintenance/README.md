# مجلد أدوات الصيانة (Maintenance Scripts)

يحتوي هذا المجلد على سكربتات الصيانة اليدوية وفحص قاعدة البيانات وتحليل ملفات الاستيراد.

---

## فهرس الملفات والمجلدات:

* `analyze_supplier_workbook.py`: تحليل ملفات Excel القديمة الخاصة بدفتر الموردين.
* `analyze_touch_dialogs.py`: فحص وتدقيق أبعاد وخصائص نوافذ اللمس.
* `check_db.py`: فحص الاتصال السريع بقاعدة بيانات MySQL.
* `reset_admin.py`: إعادة ضبط حساب المدير الافتراضي يدوياً.
* `reset_db.py`: تصفير وإعادة تهيئة جداول قاعدة البيانات يدوياً.
* `reset_sales.py`: مسح سجلات المبيعات في بيئات التجربة.
* `diagnostics/`: سكربتات التشخيص اليدوية المنقولة من مجلد `tests/` لتعمل فقط عند استدعائها صراحةً.
