# مجلد السكربتات والأدوات (Scripts)

يحتوي هذا المجلد على أدوات البناء والصيانة وفحص التغطية والسكربتات التشغيلية المساعدة.

---

## فهرس الملفات والمجلدات:

* `check_coverage_gates.py`: التحقق من عتبات تغطية الاختبارات الآلية.
* `run_coverage.ps1`: سكربت PowerShell لتشغيل قياس التغطية وتوليد التقارير.
* `git/`: سكربتات مساعدة لرفع التعديلات إلى Git.
* `maintenance/`: أدوات الصيانة والتحقق والتشخيص اليدوية.
* `pyinstaller/`: سكربتات بناء الحزمة التنفيذية الإنتاجية (`GOLDSHOP.exe`).
